# 内置海龟汤

海龟汤是宿主内置的水平思考猜谜游戏，题库来自用户提供的 `skills-haigui-tang.zip`，共 112 道。机器人负责出题、给提示、判断问题和公布答案；每个允许的群聊或私聊各自保存一局进度。无需安装旧技能或插件。

## 开启与指令

在「游戏 → 海龟汤」中启用，并逐行填写允许的会话 `group:群号` 或 `private:QQ号`。默认关闭、名单为空。关闭后保留题库使用记录和当前进度，重新开启后可继续未过期的一局。

| 发送内容 | 效果 |
| --- | --- |
| `海龟汤` / `来一碗海龟汤` | 开局前列出简单、中等、困难各有多少道可选题；已有进行中的局会重发汤面 |
| `1` / `简单`、`2` / `中等`、`3` / `困难` | 在选题时选择 3、4、5 星难度并开始游戏 |
| `海龟汤 简单` / `海龟汤 中等` / `海龟汤 困难` | 直接指定 3、4、5 星难度开局 |
| `是不是……` / `海龟汤 问：……` / `海龟汤 猜：……` | 提问或猜测；回复只会是“是、不是、无关、部分对”，猜中完整真相时公布汤底 |
| `提示` / `海龟汤 提示` | 依次给一条提示 |
| `公布答案` | 公布汤底并结束；提问数未达到设置值时需一分钟内再发一次确认 |
| `换题` / `海龟汤 换题` | 放弃当前题并重新抽取，不公布旧题汤底 |
| `海龟汤 状态` | 重发汤面及公开进度 |
| `退出` / `海龟汤 退出` / `结束海龟汤` | 取消选题或结束本局，不公布汤底 |

难度题数按当前难度上限与黑暗向筛选计算；若某档显示 0 道，该档暂时无法开局。仅选题中会接管不带前缀的难度和数字，仅进行中的局会接管不带前缀的提示、换题和特定问句；普通群聊仍由正常聊天流程处理。明确游戏指令由宿主消费，不会再交给普通聊天编排器。

管理员还可在控制台填写目标会话、汤面和汤底，确认后直接向该会话出一碗自定义汤。汤底不会跟随汤面发送；自定义汤没有内置提示，猜中由模型判断，或由会话中的玩家要求公布答案。目标会话必须在白名单中且没有其他进行中的海龟汤。

## 判断与防剧透

出题、提示、进度和公布答案都由宿主控制。问答会调用当前聊天模型一次，模型只负责返回固定的判断枚举；它生成的自由文本不会直接发往 QQ。猜中判断还要求玩家的问题命中题库关键词，并明确表达完整猜测。模型不可用时这次问答失败，游戏进度保留。

题库里有黑暗、案件和轻口味标签；可关闭黑暗向题目，也可调整难度上限、闲置期限、提示次数和重复出题策略。关闭黑暗向时只从非 `dark` 标签的题目里抽取，不会因某个筛选无结果而退回黑暗题目。

状态写在 `<dataDir>/haigui-tang/state.json`。从未使用的实例不会生成该文件。控制台状态接口只返回会话、时间和题数，不返回汤底。模型判断使用正常模型 API，会消耗 Token；当前版本不单列海龟汤的用量账目。

## 维护与验收

- `node --test test/haigui-tang.test.mjs` 检查题库、指令、持久化、开关和输出边界。
- 在允许会话测试开局、连续问答、提示、猜中、公布答案、重启续局和关闭后不再接管。
- 改动 `ui/` 后依照 [UI-SMOKE.md](UI-SMOKE.md) 检查设置页布局与保存交互。
- 禁用后保留状态文件。若需手工清理，仅处理 `haigui-tang` 专有目录，勿删除其他运行数据。

原压缩包中的 `skill.json` 和 README 是旧技能的说明与提示词，不作为宿主运行时指令。题库文本仅作为游戏素材。
