# QQ Agent Plus v9.0.1

本版汇总 v9.0.0 之后的 JM 上传修复、QQ 原始历史检索、跨对话回忆改进及 B 站转发修复。保留已有配置、聊天记录、PDF 缓存和任务状态。

## JM 群文件上传

- 先使用原文件名上传；失败后回查群文件，再使用 `JM{作品ID}.pdf` 尝试一次。备用名失败即停止，错误提示与日志反映真实尝试次数，不从 `-134` 推断审核或其他拒绝原因。
- 上传前后及重试前回查群文件，复用已存在的文件，避免确认失败或缓存重发造成重复上传。无法回查时停止自动重传。
- 原 PDF、本地文件名、完整标题和元数据保留；只有编号名成功时才追加兼容提示，失败时保留已有文件。
- 修复简介图片生成在协议容器不可访问路径时发送失败的问题。用户已确认真实群文件上传恢复正常。

## QQ 历史与跨对话回忆

- 新增按关键词、日期检索 QQ 群聊／好友历史与本地已保存原文，返回来源、时间、消息 ID 和实际检索覆盖范围。
- 改进同一 QQ 号的跨窗口回忆：按话题和北京时间线索检索，减少无关片段，支持逐窗口隐私、回忆留档查看、纠错与恢复引用。
- 历史检索受账号权限、协议端记录和分页预算限制；未检索到不代表从未发生。升级不会自动启用跨窗口回忆或改变已有隐私设置。

## 其他修复

- 修复 B 站元信息 HTTP 412 导致自动转发失败：先完成视频下载，再引用原分享卡片发送封面详情与视频；改进发送状态记录及重复发送防护。
- 清理外部恢复巡检中残留的云主机重启尝试状态，保留既有恢复权限与限额。

## 升级说明

- 使用原部署流程或 Release 更新入口升级，无需删除配置、重建数据库或清理缓存。
- 本版不升级依赖，不改写原 PDF；原有业务白名单、调度与配置继续沿用。结果未知的历史发送记录不会因升级自动重放。
