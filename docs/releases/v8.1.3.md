# QQ Agent Plus v8.1.3

本次更新增加 E-Hentai 检索与 PDF、海龟汤、SerpApi 以图搜图，并翻新网页控制台。聊天、下载与自动更新链路也修复了多处异常。

## 新功能

- **E-Hentai 检索**：支持标签、关键词、昨日榜单、翻页与序号选择；完整下载后合成 PDF。失败图片可续传，PDF 和下载缓存按期限清理。新实例默认关闭，须在「功能 → E站检索」开启并授权会话。详情见 [E站说明](https://github.com/hjklggfh/qq-agent-plus/blob/v8.1.3/docs/EHENTAI.md)。
- **海龟汤**：内置 112 道题，支持三档难度、提示、猜测、公布答案、退出与会话进度保存；管理员也可发送自定义题。新实例默认关闭，须在「游戏 → 海龟汤」开启并授权会话。判断问题会调用当前聊天模型并消耗 Token。详情见 [海龟汤说明](https://github.com/hjklggfh/qq-agent-plus/blob/v8.1.3/docs/HAIGUI-TANG.md)。
- **SerpApi 以图搜图**：`找鸡` 与默认 `搜图` 使用 SerpApi 的 Google Lens 查询；可单独指定 Google、Yandex 或 trace.moe。结果标注来源类型，优先展示具体帖子；无原图时的相似图片只作为线索。SerpApi 默认关闭，需要自行提供 Key、启用平台并配置搜图中转，查询消耗账户额度。详情见 [以图搜图说明](https://github.com/hjklggfh/qq-agent-plus/blob/v8.1.3/docs/IMAGE-SEARCH.md)。
- **管理员私聊授权**：管理员可发送 `功能` 查看可用指令，并按会话查看或调整基础聊天、海龟汤、E站、跑团、JM 等功能授权。功能总开关仍由控制台管理。

## 控制台

- 总览页重新整理连接、运行、用量和异常信息；功能、游戏、记忆等入口按用途组织。点击「功能」会直接显示可切换的二级侧栏。
- 「设置 → 外观」提供主题、强调色、背景、卡片材质、版式、密度、边角、排版和动态选项。悬停、点击及鼠标拖尾可单独配置，含自定义颜色、连续光线与柔光丝带；拖尾默认关闭，系统减少动态效果设置仍生效。外观选择保存在当前浏览器。
- 会话页可区分临时兜底回复与常规回复；插件管理入口暂不在主导航展示，现有插件数据保留。

## 修复与升级提醒

- 修复回复图片后漏发消息、全响应群漏处理普通文字、定向回复保护及部分工具参数解析问题；文件名不再被误当作指令。
- 改进 E-Hentai 图片节点失败后的重新获取与续传，减少单个不可达节点导致的整本失败；仍受站点结构、网络和图片可用性影响。
- 自动更新状态写入改为串行，避免较新的失败通知被旧状态覆盖。
- 沿用原 `deploy.sh` 升级可保留配置与运行数据。E-Hentai PDF 需要 Python 3 + Pillow；SerpApi 搜图中转和可选独立代理需按各自文档配置，不会随宿主更新自动安装。
