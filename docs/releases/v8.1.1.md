# QQ Agent Plus v8.1.1

本次更新包含跑团扩展、三平台以图搜图，以及从插件迁为内置功能的 PID 搜索。

## PID 搜索内置化

- 独立入口：**设置 → PID 搜索**，不再通过插件中心安装或审批。
- 原插件配置、会话分级和去重记录自动迁移；旧文件保留供回滚。
- 发送 `PID 作品号` 或完整 Pixiv 作品链接直接取图，不调用聊天模型；`PID 作品号 21-40` 可指定页范围。
- 多页按数量、体积分批合并发送；已知页列表中间缺页可继续，缺页和后续页明确提示。
- 分级区分全年龄、R18、R18G与未知，支持可信缓存和管理员核实单个作品；会话分级保存立即生效。
- 沿用 Lolicon、pixiv.re / i.pixiv.re 原有链路，不依赖东京服务器；无代理或自定义详情接口时不尝试 Pixiv 官方直连。
- 发送未确认即停止，不自动逐张补发，避免重复图片。

[PID 搜索说明](https://github.com/hjklggfh/qq-agent-plus/blob/v8.1.1/docs/PIXIV.md)

## 以图搜图

- 接入 Google Lens、Yandex、trace.moe，支持指定平台、全部查询及失败回退。
- 支持“搜图＋图片”及回复图片发送“搜图”，明确指令不调用聊天模型。
- 可返回来源链接和匹配图片，最多附3张；优先匹配图原文件，缩略图、动画匹配帧分别标明。
- 独立中转通过 SSH 隧道连接，具备鉴权、大小与并发限制；Google 浏览器保留 Chrome 沙箱。

**使用限制：Google 当前仍可能要求验证码，不能保证无人值守可用；被拦截后暂停访问并可切换其他平台。**中转需要独立配置，升级宿主不会自动安装东京服务。

[以图搜图部署说明](https://github.com/hjklggfh/qq-agent-plus/blob/v8.1.1/docs/IMAGE-SEARCH.md)

## 跑团更新

- 独立工作台、世界观与角色卡导入、会话白名单和持久化存档。
- 多人各控制一个角色，支持编号行动、方格战斗、移动、掩体、技能和敌方回合。
- 诡秘战术模式加入22途径、序列9至5的成长、消化、材料、仪式及晋升机制。
- 退出保存暂停，正式结束需要确认；补充角色卡、世界观编写指南和导入示例。

诡秘能力为简化适配，每个序列节点一个新增能力，不是原著全部能力的完整复刻。

[跑团说明](https://github.com/hjklggfh/qq-agent-plus/blob/v8.1.1/docs/TRPG.md) · [战术模式](https://github.com/hjklggfh/qq-agent-plus/blob/v8.1.1/docs/TRPG-TACTICAL.md) · [角色卡指南](https://github.com/hjklggfh/qq-agent-plus/blob/v8.1.1/docs/TRPG-CARD-GUIDE.md)

## 升级与注意事项

- 继续使用原 `deploy.sh`，保持已有安装目录、数据目录和服务名；不要使用插件同步脚本更新宿主。
- 新实例的 PID 搜索与以图搜图默认关闭；旧 Pixiv 实例保留原启用状态及分级配置。
- PID 搜索的总页数、原文件获取仍受接口收录、网络及超时影响；未知总页数会明确提示，不能保证全本。
- 其他世界观的“建角”向导仍有诡秘途径文案问题，尚未在本版修复。
- 本次通过发布工作流的 Linux 检查后发布；本地 Windows 全量测试存在既有平台基线失败，不宣称所有平台全量全绿。
