# QQ Agent Plus v9.0.0

本版以功能管理和后台任务可观测性为主要更新，汇总自 v8.1.3 以来已完成的功能与修复。沿用原部署方式，保留已有配置、聊天记录和任务状态。

## 每晚用量与服务器汇报

- 在“功能 → 每晚汇报”开启并设置全局管理员，可按北京时间每天私聊汇报；默认时间为23:00，新实例默认关闭。
- 可选择Token、费用、连接状态、运行时长、CPU负载、内存、磁盘和I/O压力八类内容，并只读预览。
- 费用复用总览“今日成本”口径，区分估算、未定价调用与固定计费；统计截至汇报生成时，不是完整全天账单。
- 发送前持久化预约，同日去重；发送结果未知不自动重发，跨日不补发昨天的汇报。

## 功能管理与后台任务

- “功能 → 功能总览”集中展示16项功能，可搜索、按启用/关闭/异常筛选，并进入各自设置。开关继续使用原配置，没有第二套设置。
- 统一协调11项后台循环的启动、配置同步与停止，覆盖消息恢复、提醒、会话唤醒、每日动态、动态互动、群日报、群游戏、主动发言、主动私信、更新通知和每晚汇报。
- 卡片显示最近执行、最近检查完成或发送成功、最近失败时间及脱敏原因、下次检查或调度时间。检查完成不代表已经发出消息；无记录明确提示，进程内检查时间在重启后重新积累。
- 启动失败隔离，状态轮询和无关配置保存不会自动重试；群日报停止时取消在途模型请求并阻止晚到结果发送。已发出的请求无法撤回。
- systemd备份、健康巡检、进程保护、实际更新及外部worker继续独立管理。

## 同批功能与修复

- **X账号检索**：支持QQ转发卡片、公开账号近期帖子、翻页、中文翻译、原图集合及按查询结果编号获取原图。敏感标记帖保留警告提示。需要自行配置独立东京中转与浏览器登录态；宿主升级不会自动安装中转或取得账号权限。
- **既有JM搜索**：支持分页搜索卡片与编号下载，改进封面处理、群卡片受限时的文字回退及指令消费；本版不新增其他JM能力。
- **控制台体验**：改善导航与游戏入口，简化外观和拖尾设置，总览用量图仅在首次加载播放入场动画。
- **可选外部恢复**：新增独立健康巡检与受限服务恢复，先记录恢复预约再执行，减少中断后的重复操作；可选云主机正常重启须部署者显式配置凭据及权限，默认不启用强制重启。

## 升级说明

- 使用原 `deploy.sh` 或已有Release更新入口升级，无需删除配置、重建数据库或重新创建任务。
- 每晚汇报、X检索和外部恢复等新增能力需要按各自文档配置；升级不会自动启用未配置功能，也不会改变既有管理员、业务时刻及白名单。
- 结果未知的发送记录继续保留，不因升级自动重试。后台状态时间是保留记录或当前进程的观测，不是完整审计历史。
- 本版使用9.0.0版本号；配置与数据沿用8.1.x，不要求迁移。独立worker按各自部署说明管理。
