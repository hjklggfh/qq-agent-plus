# QQ Agent Plus v9.1.0

本版新增 DeepSeek 主导的多站深度资源检索（含东京受控外网读页）、抖音自动转发、JM 定时榜单与书架直达指令、百炼 RAG 记忆增强及按好友私聊运行模式，同时包含多项媒体转发、以图搜图与稳定性改进。保留已有配置、聊天记录、PDF 缓存和任务状态。

## 深度资源检索（`/找资源`）

- **AI 主导开局（Agent-First）**：带截图时先并行运行 AnimeTrace 与东京以图搜图转文字线索，第 1 轮即由 DeepSeek 自主决定直接高并发扫多站（明确片名/编号）还是先全网检索加读页查明真名（模糊剧情描述）。
- **多站聚合与东京中转加速**：聚合书音的图书馆、鲲 Galgame、真红小站、TouchGal、VNDB、Bangumi、DLsite、Steam 与全网搜索（Yahoo Japan 无过滤索引优先 + 宿主搜索）；Bangumi、TouchGal、Shinnku、VNDB、DLsite、Steam、Yahoo 均支持经东京中转加速，并放宽直连双栈握手超时避免跨国误超时。
- **东京受控外网读页（`POST /v1/webpage`）**：复用独立搜图中转提供受控只读读页能力，清洗正文保留版本/提取码/解压密码并提取前 18 条下载/网盘外链；强制全量 DNS 公网 IP 校验（重定向逐跳重检防 SSRF）、无 Cookie 只读 GET、仅放行文本响应、≤512 KB 体积与 10 秒超时限制，遇 Cloudflare 质询或登录墙明确回报，喂给模型时加数据隔离边界防提示词注入。
- **深度预算与防翻车护栏**：最高 8 轮检索、默认总超时 150 秒（控制台支持 15—300 秒）、剩余 `<20` 秒自动切换终轮打包输出；支持重复工具调用去重、连续 2 轮无新增结果软提示，以及深挖超 20 秒单次进度提醒。
- **卡片排版与防风控开关**：精简为 3 条合并气泡、结果条目之间空行分隔、封面图经 `sharp` 统一转码；群聊 `[.]` 链接混淆默认关闭，可在控制台按需勾选开启。

## 抖音与 B 站媒体自动转发

- 新增抖音视频与图文作品免登录解析与自动转发，支持在控制台配置首选画质（默认 720p）。
- 抽取公共媒体转发层，持续优化 B 站视频与图文卡片转发稳定性。

## JM 禁漫增强

- 新增每晚 23:50 日榜/周榜自动推送、同人分类榜单（默认 Top 48、上限 60），停用陈旧缓存回退并如实回报失败原因。
- 新增 `JM帮助`、`JM书架`、`JM更新` 等直达命令（独立于主模型限流），并支持 12 小时并发日更采集。
- 支持残缺 PDF 标记、缺失页原地续补与旧群文件替换；优化慢 CDN 限时与流式图片校验下载，补齐私聊编号名上传回退。

## 记忆检索、私聊与运维改进

- 新增百炼 RAG 记忆检索增强与控制台专用设置页，默认 rerank 模型升级为 `gte-rerank-v2` 并优化测试报错展示。
- 新增按好友粒度的私聊运行模式配置。
- 以图搜图支持 trace.moe 去黑边与成人条目保留、可配置附图数量上限；每晚汇报切换为截至发送时的滚动 24 小时统计，并在发送前实时刷新 Antigravity 配额。
- 拦截模型输出的假贴纸占位文本并优先前缀查表；修复代码审计中定位的多项逻辑、资源泄漏与异步竞态问题。

## 升级说明

- 使用原部署流程或 Release 更新入口升级，无需删除配置、重建数据库或清理缓存；原有白名单、调度与数据目录继续沿用。
- 本版新增 `opencc-js` 依赖（`deploy.sh` 会自动安装）。
- 如需启用 Bangumi / TouchGal / Shinnku / VNDB 中转加速及 `/v1/webpage` 外网读页，请同步更新独立运行的东京 `qq-image-search-relay` 服务。
