# JM 禁漫下载插件

`jm-suomingor` 是项目内置的单功能原生插件适配。它把原 skill 的 JM 下载能力接到当前插件宿主，不引入通用 skill 生命周期或完整插件市场兼容层。

## 启用顺序

1. 在“插件”页面启用 `jm-suomingor`。
2. 确认插件声明的能力，尤其是 `JM 专用 OneBot 操作`。
3. 在“设置 → JM 禁漫下载”配置参数并保存。
4. 重启服务使插件设置生效。

设置页不会代替插件启用和能力确认。插件状态、任务记录、下载图片、PDF 和缓存统一写入：

```text
<dataDir>/plugin-state/jm-suomingor/
```

## 支持的工具

- `jm_download_album`：按 JM 编号或链接异步下载整本漫画。
- `jm_control`：暂停、继续或删除任务。
- `jm_group_toggle`：按群开启、关闭或查询 JM 功能。
- `jm_task_status`：查看当前会话的任务进度和历史。
- `jm_today_list`：查看本地书架的今日列表。
- `jm_daily_updates`：查看站点日更清单。
- `jm_library`：查询本地已保存的漫画。
- `jm_storage`：检查下载目录、PDF 能力和群文件配额。

下载工具立即入队，实际下载、竖切还原、PDF 合成和文件上传在后台执行。完成或失败消息会发回触发请求的当前群聊或私聊。

## 设置项

设置页覆盖原适配的主要参数：输出 PDF/原图、竖切还原、最大页数、并发、超时、PDF 质量和尺寸、成品缓存、原图清理、单文件大小、超限策略、群文件配额检查、群文件保留、本地保留、备用域名、代理、允许触发的 QQ、合集下载、进度提示、日文标题翻译和 Python 路径。

Python + Pillow 用于竖切还原和 PDF 合成。环境缺少它时，下载仍可用，但会降级为原始图片。日文标题翻译使用宿主已有模型配置，并在插件状态目录缓存结果。

## 安全边界

插件声明的 `jm:onebot` 是受控高风险能力，不是通用 OneBot 客户端。它只允许：

- 当前群的群文件上传、查询、删除、配额查询、群成员权限查询和群信息查询；
- 当前私聊对象的文件上传；
- 当前会话的文本、图片和文件消息段发送。

所有目标会话由宿主强制绑定，插件不能访问其它群或私聊。

## 从原 skill 的适配

原始实现保留在插件目录的 `legacy-index.js`，`index.js` 提供当前宿主要求的 `activate(api)` 入口、工具名称映射、状态目录、网络响应和受控 OneBot 适配。原 skill 的通用生命周期钩子没有开放给插件宿主；JM 的权限和来源判断在工具调用适配中完成。
