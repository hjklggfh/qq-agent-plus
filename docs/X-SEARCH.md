# X 账号检索（试用版）

入口为控制台「功能 → X 账号检索」，默认关闭。数据来源可选官方 API 或东京浏览器登录态。官方模式需 Bearer Token，可能计费；东京模式使用独立中转令牌，无需官方 API Key。没有对应凭据时不会假装取得帖子。不与搜图或 PID 的代理设置混用。

## QQ 使用

- `X @用户名`、`X搜索 用户名`：精确查询账号最近 5 条帖子。
- 完整 `https://x.com/用户名` 或 `https://twitter.com/用户名`：同上。
- `X下一页`：官方模式查看更早的帖子，分页状态按会话与发起者隔离，10 分钟过期，重启后重新查询。东京模式目前仅支持最近 5 条，没有下一页。
- 暂不支持昵称模糊搜索、订阅推送或视频下载。普通“下一页”和数字不被接管，不影响 JM。

返回最多五条帖子节点和一条说明节点，格式参考 JM 合并转发。默认排除回复与转帖；按帖子 ID 倒序，每帖含北京时间、正文摘要及原帖链接。长文超过 1800 字截断，全文看原帖。最多两张缩略图／帖，串行下载、完整解码、压缩为 JPEG；视频／动图仅封面和链接。X 标为敏感内容的帖子仅提供链接，不转发正文或配图。

## 配置与测试

### 东京浏览器登录态

东京使用独立用户服务 `qq-x-browser-relay.service`，只监听 `127.0.0.1:3223`；QQ 服务器通过 SSH 隧道映射同一端口。控制台选择“东京浏览器登录态”，填写 `http://127.0.0.1:3223` 与独立中转令牌。X Cookie 和账号密码不离开东京，也不填入 QQ 配置。

用户先通过临时 noVNC 桌面手动登录专用 Chrome 目录，完成后关闭临时桌面，释放目录锁。每次查询只为指定公开账号启动一个有沙箱的无头 Chrome，读取其公开时间线响应和页面，查询完成关闭浏览器，保留登录目录。API 捕获仅限该页面自然返回的 `UserTweets`／`UserOriginalsTimeline` 响应，不导出 Cookie、不读取私信或推荐首页。自动翻译页面时优先使用时间线原文，无法取得可靠内容则报错。按账号核对作者，排除置顶、转帖和回复；浏览器版暂不支持这些筛选开关或翻页。网页变化或登录验证可能导致失败，届时手动重新登录，不自动破解验证码或反复重试。

独立读取进程无需额外 npm 依赖，使用已有 Node 22 和 Chrome：

```bash
X_BROWSER_PROFILE=/path/to/dedicated/profile \
X_BROWSER_RELAY_TOKEN_FILE=/path/to/private/relay-token \
node src/features/x-search/browser-relay.js
```

令牌文件最少 32 个字母、数字、`_` 或 `-`，文件权限 `0600`，目录 `0700`。默认回环端口 3223；不可公开暴露 Chrome 调试端口或该 HTTP 服务。服务内存缓存最多 30 个账号、60 秒，不保存帖子历史；单任务、45 秒超时、客户端断开取消。桌面登录与读取应互斥，推荐通过 systemd `Conflicts=` 管理；关闭页面不会退出 X 账号。首次连通预览不会发送 QQ。

### 官方 API

配置保存立即生效。两种 Token 输入留空保留，勾选清除后保存才删除；控制台和日志不回显 Token。官方 API 地址须为 HTTPS 根地址，支持 `/2/users/by/username/:username` 和 `/2/users/:id/tweets`，返回官方 v2 JSON 结构。使用当前官方文档的 `post.fields` 与 `note_post`，兼容旧响应的 `note_tweet`；不保证任意第三方接口直接兼容。

“试查最近帖子”使用已保存的配置，只在网页展示结果，不发 QQ；需先启用功能。每次最多请求五条；首次查询结果缓存 60 秒，最多 30 页；超时 5—60 秒；按人冷却 5—300 秒，全局单任务。没有自动后台轮询或浏览器进程。缓存只在内存中，关闭／配置变更会清空缓存及翻页状态，不创建数据库或删除已有用户数据。

API 调用进行公共 DNS 校验、固定已验证 IP，拒绝内网和重定向；凭据仅发送至配置的 API，不发给图片域名。缩略图仅接受 `pbs.twimg.com`；单张下载不超过 2 MiB，像素不超过 1200 万，输出不超过 160 KiB。网络不通时检查服务器访问 X 的能力，或另行配置兼容中转。

## 发送与回退

明确指令在异步查询前消费，重复平台消息不重复处理。遵守聊天白名单、活跃时段、暂停／观察模式，跑团接管优先；发送经宿主 outbox。群历史中的序号 0 不算送达，确认缺失时只再尝试一次文字卡片；查询未知、发送超时或文字卡片仍未确认时停止自动发送，不宣称成功。关闭功能或修改设置会取消在途任务。

停用可关闭此功能，其他功能和已有配置保留；重新启用不自动重发历史查询。测试入口：`node --test test/x-search.test.mjs test/x-search-ingest.test.mjs test/x-browser-relay.test.mjs`。

官方接口：[账号查询](https://docs.x.com/x-api/users/lookup/introduction)、[近期帖子](https://docs.x.com/x-api/users/get-posts)、[费用](https://docs.x.com/x-api/getting-started/pricing)。
