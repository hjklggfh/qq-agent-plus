# 跨对话认人与具体回忆

入口：「设置 → 记忆整理 → 跨对话认人与回忆」。既有人物印象仍按QQ号全局管理；
本功能补充其他窗口的具体消息片段。升级默认不自动启用；启用后默认不打开聊天隐私。
隐私关闭意味着同一人在允许群聊与私聊里的内容可以用于当前回答。

```json
{ "memory": { "crossChat": {
  "enabled": true, "privacy": false, "maxChars": 1200, "maxMessages": 4, "lookbackDays": 30
} } }
```

只认本轮实际说话者的QQ号，不用昵称推测身份；每次最多2人、2个来源窗口。
从现有SQLite消息库按发送者索引读取最近120条候选；有关键词时额外取最多120条匹配候选，
可以找到被近期闲聊挤到后面的旧消息。按当前话题匹配度优先、时间次之排序，未命中不塞入无关记录。
自动识别昨天、前天、今天、近期和私聊/群聊线索；日期按北京时间。不是完整语义搜索，
含糊的代词仍可能没有结果；可以通过工具追加更明确的关键词。
群聊只补充明确 `target_user_id` 对应此人的机器人回复；私聊取其发言后5分钟内、下一次发言前的回复。
不会混入其他人的发言、游戏秘密事件、被禁止会话或被屏蔽成员的消息。
保留的记录不完整时，不声称记得整段历史；清理掉的存档不能恢复。

默认自动回忆最多4条、合计1200字符（含来源、时间、说明）；balanced模式最多900字符，
aggressive最多600字符。未命中不添加提示词，不调用额外模型，不复制消息建第二套记忆库。
`recall_conversations` 可按QQ号及短关键词追加检索，每轮最多2次，每次使用同样预算。
字符上限不是精确Token上限，工具定义及模型回答也有成本。动态片段在用户上下文中，保持系统前缀稳定。

同一轮的自动回忆和追加检索去除重复片段；生命周期续接只有在旧片段确实随原模型上下文保存时，
才跨轮去重。片段指纹与模型上下文在同一事务中提交；重启可延续，线程关闭或上下文滚动后重新提供证据。
普通独立运行仍提供必要片段，避免为了去重而失忆；内容改动会形成新指纹。

## 每个窗口的隐私规则

设置页可以逐个添加群号或私聊QQ，分别控制「提供回忆」「使用别处回忆」「独立隐私」。
独立隐私同时隔离输入和输出方向；全局隐私和既有可见性限制优先。移除规则恢复默认，保存后生效。
规则保存在 `memory.crossChat.chats`，例如：

```json
{ "private:12345": { "allowSource": false, "allowTarget": true, "privacy": false } }
```

印象同样执行来源和目标规则；混合了受限制来源的印象保守过滤。来源权限、纠错或隐私变化会
中断在途聊天并关闭旧生命周期；会话交接摘要带策略指纹，变更后不继续使用旧策略的摘要。
旧版未带来源策略的交接，在新增隔离规则或排除项后也不再注入。数据保留，不需要删除文件。

## 查看与纠错

「回忆记录与纠错」列出最近60次含回忆检查的运行，显示实际注入字符与去重省下的字符。
打开可见查询线索、原窗口、时间、QQ号、具体节选，以及本轮注入/沿用旧上下文的区别。
记录复用原有运行留档，不新增后台采集或第二套历史库，保留期限遵守原运行留档设置。

「这条记错了」与「以后不再引用」均将所选真实消息排除出后续回忆，分别记录原因；
可以恢复引用。排除项持久化在配置中，最多500条；只认留档中存在的片段，不接受请求任意伪造文本。
排除发言时也不带出其配对的机器人回复；排除单条回复不影响原发言。纠错不修改原聊天记录，
也不能撤回已发送到当前窗口的内容。管理员查看留档的权限不受模型隐私开关影响。

所有接口使用控制台鉴权：`GET /api/recall-traces`、`GET /api/recall-traces/:sessionId`、
`POST /api/recall-exclusions`；纠错写入需要显式确认，并记录无正文的审计信息。

「开启聊天隐私」优先于回忆开关：不查询、不注入其他窗口原文，印象只接受纯当前窗口来源，
拒绝混合来源与来源不明的印象；暂不注入旧交接和线程摘要。切换可见性/访问范围会取消
在途聊天并关闭旧线程；生命周期提示词指纹也包含该策略，重启后不会复用旧策略上下文。
本轮读到跨窗口片段后不允许通过 `memory_append` 改存为当前窗口印象。
存档和人物数据保留，关闭隐私后可再次按权限使用。已经发到QQ当前窗口的消息无法撤回，
它们仍属于当前窗口历史；该开关不是删除历史或遗忘已公开内容。

旧 `memory.visibility.mode=perChat` 同样禁止跨窗口片段；
`hidePrivateInGroup=true` 继续阻止私聊原文进入群聊。需要完整跨窗口回忆时选全局可见性，
关闭隐藏私聊来源和聊天隐私。控制台管理员仍可管理原有存档。

`ChatStore.recallPersonMessages()`、`buildUserPrompt()`、`recall_conversations`。
